## Behaviour

1. Cold start: `docker compose up -d --wait --wait-timeout 90` exits 0 within 90 s on a machine that already has the images pulled. Document in `docs/local-infra.md` that the first run pulls ~2 GB and may exceed 90 s; `docker compose pull` first.
2. Kafka runs KRaft single-node (`KAFKA_PROCESS_ROLES=broker,controller`, `KAFKA_NODE_ID=1`, a fixed `KAFKA_CLUSTER_ID`), `auto.create.topics.enable=false`. Topics are created by services in later milestones; this task creates none.
3. Postgres init SQL under `infra/postgres/` creates database `ledger` only if it does not exist. No tables — the ledger schema is M1-T4.
4. MinIO: a one-shot `minio-init` service (image `minio/mc`) creates bucket `$MINIO_BUCKET` with versioning enabled, then exits 0. It is `depends_on: minio: condition: service_healthy` and must not keep the stack "unhealthy" after it exits (`restart: "no"`).
5. OpenSearch: `discovery.type=single-node`, `DISABLE_SECURITY_PLUGIN=true`, `DISABLE_INSTALL_DEMO_CONFIG=true`. Do **not** install analysis plugins here; ICU and phonetic come with M3-T3 (note this in `docs/local-infra.md`).
6. All containers are on one compose network named `title`. Nothing is exposed on `0.0.0.0`.
7. `docker compose down -v --remove-orphans` leaves no containers, networks or volumes with the project prefix.
8. `docs/local-infra.md` lists every service, port, credential source, and the exact commands to reset state.

## Acceptance criteria (each verifiable by a command or a named test)

1. `cp .env.example .env && docker compose config --quiet` → exit 0 (compose file validates).
2. `docker compose pull && docker compose down -v; time docker compose up -d --wait --wait-timeout 90` → exit 0; wall time under 90 s. Quote the time.
3. `docker compose ps --format json | python -c "import sys,json; rows=[json.loads(l) for l in sys.stdin if l.strip()]; print({r['Service']: r.get('Health','') for r in rows})"` → all five long-running services report `healthy`; `minio-init` is exited with code 0.
4. `bash scripts/infra-smoke.sh` → exit 0 and prints one OK line per store.
5. Negative: stop postgres (`docker compose stop postgres`) → `bash scripts/infra-smoke.sh` exits non-zero and names postgres. Restart it.
6. `docker compose down -v --remove-orphans && docker volume ls -q | grep -c title-engine` → `0`.
7. `grep -c '0.0.0.0' docker-compose.yml` → `0`.
