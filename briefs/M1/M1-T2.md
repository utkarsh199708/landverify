**Milestone:** M1

## Goal

After this task, `libs/events` defines a typed payload for each of the eight HLD §5 events with committed JSON Schemas, can serialise/deserialise envelopes deterministically, publishes to and consumes from Kafka with helpers, and drops duplicate deliveries by idempotency key.

## HLD references

- §5 End-to-end flow — the eight trigger events and their stage: `case.created`, `parcel.resolved`, `acquisition.complete`, `docs.gated`, `findings.emitted`, `review.needs_input`, `opinion.signed`, `report.sealed`; "A case can only move forward on an event".
- §4 — "nothing calls the next stage directly, so any stage can be re-run, replayed, or replaced by a human"; CLAUDE.md "Events are the only cross-stage call".
- §9 — "Event log (Kafka …): every stage event with payload hash; replay a case from any stage; 90 days hot".
- §5 — replay from `acquisition.complete` is a supported operation (M1-T7 builds on the consumer helper here).
- CLAUDE.md non-negotiable 8 (determinism) and "Dates: ISO-8601 with zone".

Codec (deterministic JSON):

```java
public final class EventCodec {
  public static String toJson(EventPayload p);                   // canonical: keys sorted, no whitespace, dates ISO-8601 UTC, Optional absent = omitted, enums via wire()
  public static EventPayload fromJson(EventType t, String json); // strict: unknown fields → EventDecodeException
  public static EventEnvelope envelope(EventPayload p, TenantId tenant, String producer, OffsetDateTime occurredAt,
                                       String idempotencyKey);   // eventId = UUID v5 of (idempotencyKey) — NOT random; payloadHash = PayloadHash.sha256Hex(toJson(p)); payloadJson = toJson(p)
  public static String envelopeToJson(EventEnvelope e); public static EventEnvelope envelopeFromJson(String json);
}
public class EventDecodeException extends RuntimeException
```

## Behaviour

1. Determinism: `toJson` is byte-stable for equal payloads; `eventId` is derived (UUID v5, namespace fixed constant in `EventCodec`, name = idempotencyKey) so re-publishing the same logical event yields the same envelope id. No `UUID.randomUUID()`, no `now()` anywhere in `libs/events`.
2. `fromJson` rejects unknown fields, missing required fields, and enum values not in `wire()`; error names the field.
3. `IdempotentConsumer.pollOnce`: for each record, decode the envelope; if `store.markIfAbsent(group, idempotencyKey)` is false, skip (log at debug, count as duplicate); else call the handler; commit offsets only after the batch is handled. A handler exception propagates and offsets are not committed for that batch.
4. `KafkaEventPublisher.publish` uses `acks=all`, `enable.idempotence=true`, synchronous `get()`; caller's props may override serialisers but the helper sets key/value serialisers to String if absent.
5. `TopicAdmin.ensureTopics` is safe to call repeatedly; configures `retention.ms` = 90 days, `cleanup.policy=delete` (not compact — see `docs/events.md` for why: compaction would keep only the latest event per case key and defeat replay). Write this reasoning into `QUESTIONS.md` under `M1-T2` as a note to the human, since HLD §9 says "compacted topics per case".
6. Integration tests use Testcontainers Kafka (`apache/kafka:3.8.0` via `org.testcontainers:kafka` `KafkaContainer`/`ConfluentKafkaContainer` — use whichever supports the apache image in the pinned version; else `confluentinc/cp-kafka:7.6.1` and say so). Docker is available locally and in CI.
7. Dependencies (`gradle/libs.versions.toml`; reference from `libs/events/build.gradle.kts` only): `org.apache.kafka:kafka-clients` 3.8.0; reuse the catalog's jackson (databind, jdk8, jsr310) and victools entries; test: `org.testcontainers:kafka` 1.20.1, `org.testcontainers:junit-jupiter` 1.20.1, `org.slf4j:slf4j-simple` 2.0.13 (test runtime only, to silence kafka-clients). Nothing else.
8. `libs/events` depends on `libs/domain` (`api` scope) and nothing else at runtime besides kafka-clients and jackson.
9. `docs/events.md`: one table (event → producer stage → consumer stage → payload fields), the topic/key/header contract, the idempotency contract, and the compaction note.

## Acceptance criteria (each verifiable by a command or a named test)

1. `make lint test` → exit 0.
2. `./gradlew :libs:events:exportSchemas && git status --porcelain schemas/` → empty, twice.
3. Test `EventCodecRoundTripTest#round_trips_every_event` (parametrised over all eight) passes: payload → json → payload equals, and json → payload → json is byte-identical.
4. Test `EventCodecTest#unknown_field_is_rejected` and `#unknown_enum_value_is_rejected` pass.
5. Test `EventCodecTest#event_id_is_derived_from_idempotency_key` passes: same key → same eventId; different key → different.
6. Test `IdempotentConsumerTest#duplicate_delivery_is_a_noop` passes: publish the same envelope twice → handler invoked once, `pollOnce` totals 1 handled.
7. Test `IdempotentConsumerTest#handler_failure_does_not_commit` passes: handler throws on first delivery; after a fresh consumer in the same group, the record is delivered again.
8. Test `PublishConsumeIT#every_event_round_trips_through_kafka` passes: for each of the eight, publish and consume from its topic; envelope equal; key equals caseId; headers present.
9. Test `TopicsTest#topic_names_are_wire_names` passes.
10. Negative: remove the `markIfAbsent` check → criterion 6's test fails; restore; quote.
11. `grep -rn "randomUUID\|Instant.now\|OffsetDateTime.now\|System.currentTimeMillis" libs/events/src/main` → no matches.
