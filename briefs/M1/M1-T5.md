## Goal

After this task, the case service records every cost line item for a case (model, OCR, transcription, portal fee, runner fee) in integer paise and exposes a summary whose totals equal the sum of the line items to the paisa.

## Interfaces (exact — copy, do not paraphrase)

Migration `V2__cost_ledger.sql`:

```sql
CREATE TABLE cost_ledger (
  seq          BIGSERIAL PRIMARY KEY,
  tenant_id    TEXT        NOT NULL,
  case_id      TEXT        NOT NULL,
  kind         TEXT        NOT NULL CHECK (kind IN ('model','ocr','transcription','portal_fee','runner_fee')),
  amount_paise BIGINT      NOT NULL,          -- may be negative for corrections/refunds
  description  TEXT        NOT NULL,
  reference    TEXT        NOT NULL,          -- e.g. model call id, portal receipt, runner task id
  occurred_at  TIMESTAMPTZ NOT NULL,
  actor        TEXT        NOT NULL
);
CREATE INDEX cost_ledger_case_idx ON cost_ledger (tenant_id, case_id, seq);
-- append-only like the audit ledger: reuse audit_ledger_deny() for UPDATE/DELETE/TRUNCATE triggers named cost_ledger_no_update / _no_delete / _no_truncate
```

Java (package `com.titleengine.casesvc.cost`):

```java
public enum CostKind { MODEL("model"), OCR("ocr"), TRANSCRIPTION("transcription"), PORTAL_FEE("portal_fee"), RUNNER_FEE("runner_fee"); public String wire(); public static CostKind fromWire(String) }
public record CostLine(TenantId tenantId, CaseId caseId, CostKind kind, Money amount, String description, String reference, OffsetDateTime occurredAt, String actor)
public record CostLineRow(long seq, CostLine line)
public interface CostLedger {
  CostLineRow append(CostLine line);
  List<CostLineRow> lines(TenantId tenant, CaseId caseId);          // seq ascending
  CostSummary summary(TenantId tenant, CaseId caseId);
}
public record CostSummary(CaseId caseId, String currency /* "INR" */, SortedMap<CostKind, Money> byKind, Money total, long lineCount)
   // byKind contains every CostKind (zero if none); total == sum of byKind == sum of lines, all in paise
```

```
  201 {"seq":1}
```

Numbers in JSON are integers (paise). Never a decimal.

## Behaviour

1. `append` inserts one row; the trigger denies later modification. Corrections are new negative lines.
2. `summary` computes totals in SQL (`SUM(amount_paise)` grouped by kind) and in Java cross-checks against `lines()`; a mismatch throws `IllegalStateException` (defensive — should never happen).
3. The controller maps `X-Tenant-Id` to `TenantId`; missing header → 400. Cross-tenant reads return 404 (do not reveal existence).
4. Tests use the Testcontainers Postgres wiring from M1-T4 (reuse its base test class if one exists; otherwise a shared static container with `@ServiceConnection`).
5. No floats anywhere: a test scans `services/case/src/main` for `double`/`float`/`BigDecimal` in the `cost` package → zero.
6. `docs/cost-ledger.md`: table, kinds, the paise rule, the endpoints, and the ₹150 / ₹900 targets from HLD §8/§11 as the numbers M7-T4 metrics will compare against.

2. Test `CostLedgerTest#summary_matches_lines_to_the_paisa` passes: 50 random lines (seeded RNG, mixed signs, all kinds) → `total` equals the Java sum of `amount.paise()` and every `byKind` equals its filtered sum.
3. Test `CostLedgerTest#every_kind_present_in_summary_even_when_zero` passes.
4. Test `CostLedgerImmutabilityTest#update_delete_truncate_denied` passes (SQLSTATE 42501).
5. Test `CostControllerTest#get_returns_integer_paise_json` passes and asserts the body contains no `.` inside numeric values (regex on the JSON).
6. Test `CostControllerTest#cross_tenant_read_is_404` passes.
7. Test `CostControllerTest#missing_tenant_header_is_400` passes.
8. Test `NoFloatsTest#cost_package_has_no_floating_types` passes.
9. Negative: change `SUM` to `SUM(...)::float` or introduce a `double` accumulator → criterion 2 or 8 fails; restore; quote.
