# M1-T1: Domain model (`libs/domain`) with JSON Schema export

**Milestone:** M1
**Agent:** coder
**Branch:** `wave/M1-T1`
**Depends on:** M0 (closed)

## Goal

After this task, every entity in HLD §3 exists as an immutable Java type in `libs/domain`, the `Finding` constructor rejects empty evidence, category and kism can only be built as sourced dated facts, and a committed JSON Schema exists per entity with a drift test.

## HLD references

- §3 Domain model — the entity table (Case, Parcel, Document, Party, TitleLink, Chain, Encumbrance, LitigationHit, Finding, Report) and the three deliberate choices: Party separate from any document; Gap is a first-class object with a reason; category and kism are dated, sourced facts.
- §6 Title engine — Score values; link origin (inferred / customary succession); gap hypothesis + verification instruction.
- §5 — the eight case states.
- §9 — Aadhaar never stored; PAN masked.
- CLAUDE.md non-negotiables 2, 4, 6, 8; conventions "Money: integer paise", "Dates: ISO-8601 with zone".
- STATUS.md deferred MAJORs from M0-T1 (picked up here, see Behaviour 9).

## Interfaces (exact — copy, do not paraphrase)

Package: `com.titleengine.domain`. All types are Java `record`s or `enum`s or `sealed interface`s. Every list field is defensively copied with `List.copyOf` in the compact constructor. Every `String` id is non-blank. Every `record` has a compact constructor validating nulls with `Objects.requireNonNull(x, "<fieldName>")`.

```java
// ids (each: record X(String value) — rejects null/blank)
CaseId, TenantId, ParcelId, DocumentId, PartyId, LinkId, FindingId, ReportId

// enums — wire names via a `wire()` method returning the exact string in the comment
enum Kism { RAIYATI("raiyati"), KHAS_MAHAL("khas mahal"), GAIR_MAZARUA_KHAS("gair mazarua khas"),
            GAIR_MAZARUA_AAM("gair mazarua aam"), BHUINHARI("bhuinhari"), KHUNTKATTI("khuntkatti") }
enum Category { ST, SC, BC, GENERAL }                     // wire: "ST","SC","BC","General"
enum DocumentSource { PORTAL, UPLOAD, RUNNER, TRANSCRIPTION }
enum Script { DEVANAGARI, ENGLISH, KAITHI, URDU }
enum TrustLevel { OFFICIAL_RECORD, CERTIFIED_COPY, HUMAN_TRANSCRIPTION, BORROWER_SUPPLIED }
enum InstrumentType { SALE, GIFT, RELEASE, PARTITION, SUCCESSION, COURT_DECREE, SETTLEMENT, SUB_LEASE_ASSIGNMENT }
       // wire: "sale","gift","release","partition","succession","court decree","settlement","sub-lease assignment"
enum LinkOrigin { RECORDED, INFERRED, CUSTOMARY }
enum MutationStatus { NOT_APPLIED, APPLIED, RECORDED, OBJECTED, UNKNOWN }
enum ValidationStatus { UNVALIDATED, VALID, DEFECTIVE, VOID }
enum EncumbranceType { MORTGAGE, CHARGE, LIS_PENDENS, LEASE, RESTORATION_CLAIM, REVENUE_COURT_PROCEEDING }
       // wire: "mortgage","charge","lis pendens","lease","restoration claim","revenue court proceeding"
       // (reworded after review 2026-09-19: statute names such as "s.71A" never appear in the model; the state pack cites them)
enum Forum { CIVIL_COURT, SAR, DCLR, CO }
enum Severity { BLOCKER, MAJOR, MINOR, INFO }            // ordinal order = severity order, BLOCKER highest
enum CaseState { RECEIVED, ACQUIRING, PROCESSING, ANALYSING, IN_REVIEW, BLOCKED, SIGNED, DELIVERED }
       // wire: "Received","Acquiring","Processing","Analysing","InReview","Blocked","Signed","Delivered"
enum Score { CLEAR, CLEAR_WITH_CONDITIONS, DEFECTIVE, NOT_MARKETABLE }
       // wire: "Clear","Clear with conditions","Defective","Not marketable"
enum ReviewDecisionKind { ACCEPT, OVERRIDE, VERIFY }

record Money(long paise)                                   // any long; INR implied; no floats anywhere in the model
record BoundingBox(double x, double y, double w, double h) // normalised 0..1, w,h > 0; rejects out-of-range

sealed interface EvidencePointer permits DocumentEvidence, TranscriptEvidence, RuleEvidence
record DocumentEvidence(DocumentId documentId, int page, BoundingBox region)      // page >= 1
record TranscriptEvidence(DocumentId documentId, int line)                        // line >= 1
record RuleEvidence(String ruleId, String packVersion, SortedMap<String,String> facts) // facts non-empty; SortedMap for determinism

record CategoryFact(Category category, LocalDate asOf, DocumentId sourceDocument, EvidencePointer evidence)
record KismFact(Kism kism, LocalDate asOf, DocumentId sourceDocument, EvidencePointer evidence)
   // both: evidence must be DocumentEvidence or TranscriptEvidence whose documentId equals sourceDocument; else IllegalArgumentException

record NameVariant(String text, Script script, Optional<String> fathersName)
enum PartyRole { HOLDER, TRANSFEROR, TRANSFEREE, BORROWER, HEIR, LITIGANT, OTHER }
record Relationship(PartyId other, String kind)          // kind e.g. "father", "spouse"; free text for now
record Party(PartyId id, String canonicalName, List<NameVariant> variants, PartyRole role,
             List<CategoryFact> categoryFacts, Optional<String> panMasked, List<Relationship> relationships)
   // panMasked, if present, must match ^[A-Z]{3}X[A-Z]X{4}[A-Z]$ or ^X{5}[0-9]{4}X$-style masks: enforce "contains at least 4 'X'" and length 10
   // Party has NO method or constructor that derives a Category from a name or any other attribute

record Area(long squareMetresTimes100)                    // integer; no floats
record Parcel(ParcelId id, String district, String anchal, String mauza, String thanaNumber, String khataNumber,
              String plotNumber, KismFact kism, Optional<String> csKhatianRef, Optional<String> rsKhatianRef,
              Optional<String> flatOrHoldingNumber, Optional<Area> area, Optional<String> ulpin)

record ExtractedField(String name, String value, double confidence, EvidencePointer grounding)
   // confidence 0..1; grounding must be DocumentEvidence or TranscriptEvidence (never RuleEvidence)
record Document(DocumentId id, String type, DocumentSource source, String rawFileRef, int pages, Script script,
                List<ExtractedField> fields, TrustLevel trust)
   // every field's grounding.documentId must equal id; pages >= 1

record TitleLink(LinkId id, List<PartyId> fromParties, List<PartyId> toParties, InstrumentType instrument,
                 LocalDate date, Optional<String> registrationRef, Optional<Money> stampPaid,
                 Optional<Money> consideration, Optional<String> dcSanctionRef, MutationStatus mutation,
                 List<DocumentId> supportingDocuments, ValidationStatus validation, LinkOrigin origin)
   // fromParties and toParties non-empty; supportingDocuments non-empty unless origin != RECORDED

record Gap(LocalDate from, LocalDate to, String hypothesis, String verificationInstruction)  // from < to; both strings non-blank
record CoverageWindow(LocalDate from, LocalDate to)                                          // from < to
record Chain(List<TitleLink> links, DocumentId rootOfTitle, CoverageWindow window, List<Gap> gaps)
   // links sorted by date descending is NOT enforced here (engine's job); Chain only validates non-null

record Encumbrance(EncumbranceType type, String holder, Optional<Money> amount, DocumentId source, boolean released)
record LitigationHit(String caseNumber, Forum forum, List<PartyId> partiesMatched, double matchConfidence,
                     String stage, String relevance)      // matchConfidence 0..1; partiesMatched may be empty

sealed interface FindingSubject permits LinkSubject, DocumentSubject, ParcelSubject
record LinkSubject(LinkId id); record DocumentSubject(DocumentId id); record ParcelSubject(ParcelId id)
record ReviewDecision(ReviewDecisionKind kind, String actor, OffsetDateTime at, Optional<String> reason)
   // OVERRIDE requires reason present and non-blank
record Finding(FindingId id, Severity severity, String ruleId, String packVersion, FindingSubject subject,
               List<EvidencePointer> evidence, String machineRationale, Optional<ReviewDecision> decision,
               String verificationInstruction)
   // evidence must be non-null and non-empty → otherwise IllegalArgumentException("evidence") — NO other constructor, factory or builder may bypass this

record Case(CaseId id, TenantId tenantId, String lenderRef, ParcelId parcelId, List<PartyId> borrowerPartyIds,
            CaseState status, OffsetDateTime createdAt)
record Report(ReportId id, int version, CaseId caseId, List<FindingId> findingIds, String chainSummary,
              Optional<String> advocateOpinion, Optional<String> signatureRef, Optional<String> deliveredTo)
   // version >= 1

// schema export
public final class DomainSchemas { public static SortedMap<String,String> generate(); }   // entity simple name → JSON Schema (draft 2020-12) text, keys sorted, output byte-stable
```

Gradle task: `./gradlew :libs:domain:exportSchemas` writes `schemas/domain/<Name>.schema.json` for the ten §3 entities plus `Gap`, `Finding`-related value types are embedded via `$defs`. Files end with a single `\n`, 2-space indent, keys in insertion order as the generator emits them — and the generator must be configured for deterministic output.

## Behaviour

1. Records are the only mutable-free shape; no setters, no builders that skip validation. A `Finding` with an empty evidence list cannot exist in the JVM.
2. `CategoryFact` and `KismFact` are the only ways a category or kism appears anywhere in the model. `Party` carries `List<CategoryFact>`; `Parcel` carries `KismFact`. There is no `Category` field that is not inside a `CategoryFact`.
3. No wall-clock: nothing calls `now()`. `createdAt`/`at` are inputs.
4. No `double` for money or area. `double` is allowed only for confidences and bounding boxes.
5. `Optional` fields are never null (`Objects.requireNonNull`), and never `Optional.of(null)`.
6. Enum `wire()` strings are exactly those in the Interfaces block; a `fromWire(String)` per enum throws `IllegalArgumentException` on unknown.
7. Aadhaar: the model has no field for it. A test scans `libs/domain` source for the regex `(?i)aadhaar` and asserts zero matches outside `docs/` and that test (guards against a later "convenience" field).
8. Dependencies (add to `gradle/libs.versions.toml` and reference from `libs/domain/build.gradle.kts` only): `com.fasterxml.jackson.core:jackson-databind` 2.17.2, `com.fasterxml.jackson.datatype:jackson-datatype-jdk8` 2.17.2, `com.fasterxml.jackson.datatype:jackson-datatype-jsr310` 2.17.2, `com.github.victools:jsonschema-generator` 4.36.0, `com.github.victools:jsonschema-module-jackson` 4.36.0; test-only `com.networknt:json-schema-validator` 1.5.1. Nothing else.
9. Pick up the two deferred MAJORs from M0-T1 in the root `build.gradle.kts`: (a) apply the Java conventions only to leaf projects (`subprojects.filter { it.childProjects.isEmpty() }` or `configure(...)`), so `:libs` and `:services` container nodes get nothing; (b) move the inline JUnit BOM / jupiter / AssertJ / launcher versions into `gradle/libs.versions.toml` and reference them via the catalog (the `libs` accessor is available in `subprojects {}` through `rootProject.extensions.getByType<VersionCatalogsExtension>().named("libs")` or by moving the convention into a precompiled script plugin under `buildSrc/` — either is acceptable; say which in `DEVIATIONS`). `./gradlew projects` and `make lint test` must behave exactly as before.
10. `docs/domain.md`: one table per entity (field, type, HLD §3 source, validation), and the two invariants (evidence, sourced category/kism) stated in one line each.
