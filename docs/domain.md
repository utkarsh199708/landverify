# Domain model (`libs/domain`)

Every entity in HLD §3 is an immutable Java `record` (or `enum` / `sealed interface`) under
`com.titleengine.domain`. Lists are defensively copied with `List.copyOf`; every reference field is
null-checked in the compact constructor; ids and free text are non-blank. Money is integer paise and
area is an integer of square-metres×100 — no `double` for either. JSON Schemas (draft 2020-12) for
the ten §3 entities plus `Gap` are generated by `./gradlew :libs:domain:exportSchemas` into
`schemas/domain/` and committed; regeneration is byte-stable.

## Two invariants (checked by tests)

- **No finding without evidence.** `Finding`'s compact constructor throws
  `IllegalArgumentException("evidence")` for a null or empty evidence list; no factory, builder or
  deserialiser can bypass it (non-negotiable 2; `FindingTest`).
- **Category and kism are sourced, dated facts.** A `Category` appears only inside a `CategoryFact`
  and a `Kism` only inside a `KismFact`; each carries `asOf`, a `sourceDocument`, and evidence that
  must be grounded in that same document. Category is never derived from a name or any attribute
  (non-negotiable 4; `CategoryFactTest`, `KismFactTest`, `PartyTest`).

## Value types

`Money(long paise)`, `Area(long squareMetresTimes100)`, `BoundingBox(double x,y,w,h)` (normalised
0..1, w,h>0). `EvidencePointer` is a `sealed interface` permitting `DocumentEvidence(documentId,
page≥1, region)`, `TranscriptEvidence(documentId, line≥1)`, `RuleEvidence(ruleId, packVersion,
SortedMap facts)` (facts non-empty, sorted for determinism). Ids are single-field records
(`CaseId`, `TenantId`, `ParcelId`, `DocumentId`, `PartyId`, `LinkId`, `FindingId`, `ReportId`), each
rejecting null/blank. Every enum exposes `wire()` and `fromWire(String)` (round-trip tested).
